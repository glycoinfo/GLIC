The Wish List shows requests for new tools, or for new features in existing tools, submitted through the [request form](../wishList/index.md). For each request it shows the person or group asked to develop it (if any), the date of the proposal, a description and the planned completion date. If you have recently submitted a form to have a tool developed, it may take several minutes for it to load in the list below.

A request on this list is not a commitment that the tool will be developed. Developers will try to contact you as soon as possible for more details.

If there are any problems with the spreadsheet, please send an email to the GLIC mailing list at <glycoinformatics-consortium-glic@googlegroups.com>.
