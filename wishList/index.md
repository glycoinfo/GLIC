---
title: Request a computational resource
description: Tell GLIC about a glycoscience tool or database you need
---

Is there a glycoscience analysis or data-management task for which you cannot find a suitable tool or database? Describe what you need using the form below. You can ask for a new tool, or for a new feature in an existing one.

The form asks for:

* your name and email address, so that you can be contacted about the request;
* whether you want a new tool (stand-alone software, web application or web service) or a new feature in an existing tool, and a description of what it should do;
* optionally, a person or group you would like to develop it, and a preferred completion date.

Submitting a request helps GLIC see what the community needs. It does not guarantee that the tool will be developed. Requests are listed on the [Wish List](../toolsList/index.md).

Before submitting, you may want to check the [Software](../software/index.md) and [Databases](../database/index.md) lists. For questions, write to the [GLIC mailing list](https://groups.google.com/g/glycoinformatics-consortium-glic).
